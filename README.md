# TODO アプリ

ブラウザで動くシンプルな TODO アプリです。依存ライブラリもビルドも必要ありません。

公開版: https://gh-todo.vercel.app

## 使い方

公開版を開くか、`index.html` をブラウザで開きます。

| 操作 | 方法 |
| --- | --- |
| 追加 | 入力して Enter、または「追加」 |
| 完了・未完了の切り替え | チェックボックス |
| 編集 | タイトルをダブルクリック、または「編集」 |
| 編集の確定・取り消し | Enter または欄外をクリックで確定、Esc で取り消し |
| 削除 | 「削除」または「完了済みを削除」 |
| 削除の取り消し | 直後に表示される「元に戻す」（直前の 1 回分） |
| 絞り込み | すべて / 未完了 / 完了済み |

## データの保存

データはブラウザの `localStorage`（キー `gh-todo:v1`）に保存します。サーバーには送信しません。

- ブラウザや端末をまたいだ同期はできません。
- ブラウザのサイトデータを削除すると、タスクも消えます。
- 同じブラウザの複数のタブでは、変更が自動で反映されます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 見た目（OS の設定に合わせてライト・ダークを切り替え） |
| `app.js` | 描画とイベント処理 |
| `todo-core.js` | 状態の操作と保存処理（DOM に依存しない） |
| `test/todo-core.test.js` | `todo-core.js` のテスト |

## テスト

Node.js 18 以降で実行します。

```sh
node --test
```
